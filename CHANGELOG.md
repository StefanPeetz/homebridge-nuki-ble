# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0]

- Initial scaffold: Dynamic Platform Plugin (TypeScript)
- Python bridge for pyNukiBT BLE communication
- LockMechanism service: Lock / Unlock / State
- Battery service: level and low-battery status
- Optional Unlatch switch per device
- Optional Calibrate switch per device
- Advanced Config: Detached Cylinder mode (BLE-only)
- Pairing helper script
- Serial action queue per lock to prevent BLE collisions
- Auto Release & Publish GitHub Actions
